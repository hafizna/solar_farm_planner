# Sharing one HTML file and online sources

## Current portable release

The shareable HTML now focuses on **local login ? map**. Screening & Koridor, the project home page, its online enrichment and its raster/geometry libraries are omitted from this edition. RUPTL, GI, land lists and other existing map references remain available. The file is about 1.2 MB. Local/Vercel development retains the full screening workflow described below. Login collects a local display name; it is not server authentication.

## Send the app without hosting

`npm run build` creates **`web/portable/georensis-solar.html`** (~1.2 MB). Send this file by email, chat or a shared folder. The recipient saves it and opens it with a modern browser (Chrome/Edge/Firefox). No Node, Python, localhost, account or server is needed. The demo entry is a local display name, not authentication.

The current file bundles HTML, styles, map scripts, demo datasets and Leaflet. It has no sibling-file dependency. Uploaded project data and browser changes are not automatically written back into the app file. Send a report/evidence export to share specific results. LocalStorage behavior for `file://` varies by browser; exported files are the durable handoff.

Without internet: navigation, synthetic data, parcel drawing/import, geometry, corridor comparisons and exports work. Basemap tiles and public data fetching require internet. The data collector in the portable app calls public endpoints directly. A provider may reject CORS requests, especially range requests for WorldCover; the UI records an error instead of inventing data. Use uploaded GIS data when direct access is unavailable.

A public web URL requires hosting, but a shareable HTML **file** does not. Hosting is optional and separate from this deliverable.

## Send completed results

On **Screening & Koridor**, run the comparison and choose **Unduh laporan HTML**. The resulting file includes:

- Standalone SVG map of parcel, GI candidates, constraints and routes; buttons select/highlight a route.
- Area/capacity assumptions, route table and user-supplied cost ranges.
- Online source results, acquisition timestamps, dataset periods and attribution.
- User-reported external studies and unresolved engineering tasks.
- Embedded full JSON evidence with a local download button.

Reports make no network requests. They can be opened offline, forwarded, or printed to PDF. They are snapshots; editing the source project does not update an already exported report. The previously generated `web/portable/contoh-laporan.html` remains a synthetic pilot example; it is separate from the simplified portable app and is no longer regenerated by the portable smoke test.

## One project workflow

Beranda now has one primary action, **Mulai screening**: select/draw/import a parcel → enrich data / compare alternatives → download/share a report. GI, RUPTL and the existing demo map remain supporting references.

## Optional online sources

Select the desired sources and click **Ambil data online**. Each source has an independent result: available, partial, no data, or error. Failures do not produce zeros or assumed approvals. Sources are read sequentially; user-selected location bounds are transmitted to the provider. Cached server responses retain the original fetch timestamp.

| Source | Implementation | Coverage / interpretation |
| --- | --- | --- |
| OpenStreetMap / Overpass | Eligible GI candidates, roads, waterways and selected settlement landuse ways. Public unverified features retain object IDs, tags, timestamp and ODbL attribution. | GI radius 5/10/15 km; roads/water/settlement max 5 km. Missing voltage GI and sites with >150 kV or GITET/traction tags are excluded. No voltage inference from a name. Relations without supported geometry are counted as unsupported. Completeness is not guaranteed. |
| NASA POWER | Climatology GHI ANN/monthly values, API units and reported climatology period. | Regional solar resolution ~1°. Not parcel-level irradiance validation or plant yield design. |
| Copernicus GLO-30 | STAC discovery + partial COG reads at original resolution; samples inside parcel; elevation min/max, median slope and percentage of sampled slopes >15°. | A DSM including structures/vegetation. Central differences on native pixels. Only parcel terrain is evaluated; no corridor terrain penalty is generated from isolated parcel data. Bounds limited to 0.12° per axis and 2 million pixels/window for browser memory. |
| ESA WorldCover 2021 v200 | Partial COG reads and within-parcel sampled class proportions. | Historical 10 m land cover, not legal land use, forest permit status or current ownership. No automatically excluded land based solely on a cover class. |
| InaRISK BNPB | Flood-hazard index ImageServer identify at the parcel representative point, preserving raw value. | Point sample only, not parcel/route flood coverage. `NoData` remains unknown. No class/return-period inference without the dataset definition. |

Road proximity percentages based only on OSM are evaluated within the actual road-query radius. Route percentage covered by that query is reported separately; segments outside coverage are unknown, not assumed road-free. Manual road imports have unspecified completeness and remain user-supplied.

Raster sampling uses a bounded stride for large windows. Missing pixels/tile failures result in partial coverage; raster-derived indicators do not certify geotechnical/thermal conditions. Copernicus attribution: © DLR e.V. 2010–2014 / Airbus Defence and Space GmbH 2014–2018, ESA mission-specific terms. WorldCover: ESA WorldCover 2021 v200, CC BY 4.0.

## Local/Vercel mode

`npm run dev` adds `/api/data` and `/api/raster`. The Vercel root remains `web`, with output `dist`; `web/api/*.js` provides the same Node handlers. No API keys are needed for these sources. This mode requires Node 18+ and network access.

Adapters accept only known sources and bounded Indonesian coordinates. They do not accept arbitrary upstream URLs or user Overpass programs. JSON responses are capped at 6 MB, requests time out, same-query server requests deduplicate, and successful JSON is cached in a bounded process-local cache for six hours. Cache is best-effort per process, not a shared production datastore. Public Overpass is not an SLA; at scale choose a licensed/commercial endpoint or regional extract service.

Raster proxy accepts only generated Indonesian DEM/WorldCover tile IDs, requires a single byte range capped at 4 MB and refuses whole-file responses. This avoids copying full raster tiles or depending on provider CORS when served locally/on Vercel. Portable `file://` mode has no such proxy and attempts the public CORS endpoint directly.

## Observed live verification, 15 October 2026

At the synthetic pilot coordinates around 107.756 E, -6.895 N, actual endpoint/browser checks retrieved NASA POWER climatology, Copernicus parcel elevation/slope, and WorldCover parcel classes. BNPB returned `NoData` and remains unknown. Overpass Private.coffee returned HTTP 500, the main endpoint returned HTTP 502, and the tested alternate timed out. The OSM adapter is implemented and covered by response-fixture tests, but its live retrieval could not be confirmed during this check. No public-source values are silently substituted with demo values.

## Validation

`npm run build`, `npm run test:unit`, `npm run test:e2e` (after installing Playwright Chromium). Tests cover offline `file://` startup with network blocked, report generation/selection/evidence escaping, data-source partial failures, OSM eligibility/provenance, routing/drawing and existing navigation. `scripts/verify-live.cjs` is an optional real-network check; it must be run against the current local server on port 3020 and is not part of offline CI.
